# Fix: Sección de Testimonios - Carrusel y Cards

## Problemas identificados (solo desktop)

1. **Efecto 3D tilt entra en conflicto con el carrusel**: El tilt aplica `perspective(600px) rotateX/rotateY` a las cards dentro del track que ya tiene `translateX()`. Esto distorsiona visualmente las cards (se ven cortadas/raras).
2. **`overflow: clip` en las cards**: Combinado con el tilt 3D, crea artefactos de recorte agresivos en las cards rotadas.
3. **Sin controles de navegación**: El CSS tiene estilos para flechas y dots (`.testimonials-nav`, `.t-nav-btn`, `.t-dots`, `.t-dot`) pero nunca se insertaron en el HTML. El auto-play se pausa al hacer hover y no hay forma de navegar manualmente.
4. **Wrapper con `display: flex` innecesario**: Puede interferir con el `width` y `translateX` del track.
