# Universo Musical 🎵

Sitio web oficial de **Universo Musical** — Tienda de instrumentos musicales, clases, accesorios, sonidos digitales y asesoría para eventos en **Neiva, Huila, Colombia**.

## 🌐 URL

[https://universomusicalneiva.com](https://universomusicalneiva.com)

## 🚀 Stack

- **Framework:** [Astro](https://astro.build) v6
- **CSS:** Global stylesheet (dark theme)
- **JavaScript:** Vanilla JS (interacciones, partículas, slider)

## 📦 Scripts

| Comando | Acción |
|---------|--------|
| `npm install` | Instalar dependencias |
| `npm run dev` | Iniciar servidor local en `localhost:4321` |
| `npm run build` | Build producción a `./dist/` |
| `npm run preview` | Vista previa del build local |

## 📁 Estructura

```
src/
├── components/     → Componentes reutilizables
├── data/           → Datos de productos y categorías
├── layouts/        → Layout principal con SEO
├── pages/          → Páginas del sitio
├── scripts/        → JavaScript principal
└── styles/         → Estilos globales
```
